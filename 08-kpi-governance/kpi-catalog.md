# KPI Governance

Each KPI should define:

- kpi_id
- name
- description
- formula
- grain
- numerator
- denominator
- exclusions
- time logic
- currency treatment
- owner
- source mart
- certification status

## Example KPIs

- Sales Value
- Units Sold
- Reservation Conversion
- Collection %
- Overdue Receivables
- Expected Cash 90D
- Cancellation Rate
- Available Inventory Value
- Pending Commission
