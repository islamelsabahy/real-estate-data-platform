# Core Data Quality Rules

| Rule | Severity |
|---|---|
| Duplicate active unit code in same project | Critical |
| Sold unit without active contract | Critical |
| Contract without customer | Critical |
| Contract value mismatch vs schedule | Critical |
| Receipt without allocation | High |
| Negative standard receipt | Critical |
| Unknown broker reference | High |
| Commission without rule reference | High |
| Invalid expected collection date | Medium |
| Missing project on unit | Critical |
