# Naming Conventions

Recommended prefixes:

- `stg_` staging
- `core_` canonical core
- `dim_` dimensions
- `fct_` facts
- `mart_` aggregated marts
- `dq_` data-quality objects
- `ref_` reference/master data

Use:
- snake_case
- singular core entity names
- UTC timestamps for technical metadata
- explicit currency columns where needed
